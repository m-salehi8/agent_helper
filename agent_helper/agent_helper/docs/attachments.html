پیوست تصویر

ارسال تصویر، استخراج با مدل بینایی و استفاده در افزونه

کاربر می‌تواند همراه پیام یک تصویر بفرستد (مثلاً عکس فاکتور). هسته تصویر را ذخیره می‌کند، با مدل بینایی اطلاعات را به JSON استخراج می‌کند، کنترل حسابی انجام می‌دهد و متن استخراج‌شده را به پیام اضافه می‌کند تا LLM از آن استفاده کند.

ارسال#

JSON
{"message": "این فاکتور رو ثبت کن", "image": "data:image/jpeg;base64,/9j/4AAQ..."}
  • فرمت‌ها: png، jpg، webp؛ حداکثر MAX_UPLOAD_BYTES (پیش‌فرض ۵ مگابایت).
  • مسیر ذخیره: <UPLOAD_DIR>/<user_id>/<uuid>.<ext> در default_storage.
  • با پیوست، مسیر سریع کنار گذاشته می‌شود و attachment_tags افزونه‌ها انتخاب می‌شوند.

رویدادها#

data: {"event": "tool_status", "status": "در حال خواندن تصویر پیوست..."}
data: {"event": "attachment_data", "data": {"seller": "...", "total": 23370000, "items": [...]}, "warning": ""}

اگر خواندن ناموفق باشد، رویداد error می‌آید و پیام ثبت می‌شود ولی LLM اجرا نمی‌شود.

پیکربندی مدل بینایی#

Python
AGENT_HELPER = {
    # پیش‌فرض: همان LLM_*
    'VISION_BASE_URL': 'http://vision.internal:8000/v1',
    'VISION_MODEL': 'qwen2.5-vl',
    'VISION_TIMEOUT': 90,
}

استفاده در افزونه#

مسیر فایل در محتوای پیام کاربر (message.content["attachment"]) ذخیره است؛ افزونه می‌تواند آن را به داده‌ی دامنه وصل کند (مثلاً آن را در فیلد فایل یک فرم ذخیره کند). یک قاعده‌ی پرامپت با برچسب پیوست بنویسید که مدل مقدارهای تصویر را منبع فرم بداند و مقدار مبهم را بپرسد.

مقدارهای ماشینی

استخراج تصویر ممکن است خطا داشته باشد؛ همیشه در کارت پیش‌نمایش به کاربر نشان دهید و اجرا را به دکمه بسپارید.
