نصب

نصب آفلاین با wheel، افزودن به پروژه و migrate

نصب از wheel (آفلاین)#

سرورهای عملیاتی معمولاً اینترنت ندارند؛ wheelها و وابستگی‌ها را روی ماشین توسعه آماده کنید و همراه ببرید.

  1. ساخت wheel پکیج‌ها (بدون اینترنت):
    Shell
    cd packages
pip wheel --no-deps --no-build-isolation --no-index -w dist ./agent_helper ./agent_helper_demo
  2. جمع‌کردن وابستگی‌ها (یک‌بار، روی ماشینی با دسترسی):
    Shell
    pip download --only-binary=:all: -d wheelhouse \
    Django==5.0.4 djangorestframework==3.15.1 django-jalali==6.2.1 jdatetime==5.0.0 requests==2.32.3
  3. نصب روی سرور:
    Shell
    pip install --no-index --find-links wheelhouse --find-links dist --pre agent-helper
نسخه‌ی بتا

نسخه‌ی فعلی پیش‌انتشار است (0.1.0b1)؛ pip آن را فقط با --pre یا نسخه‌ی دقیق (agent-helper==0.1.0b1) انتخاب می‌کند.

نسخه‌ها

نسخه‌های بالا همان‌هایی است که تست شده‌اند. نسخه‌ی پایتون ماشین دانلود و سرور باید یکی باشد (wheelهای باینری مثل charset-normalizer).

نصب از سورس (توسعه)#

Shell
pip install -e packages/agent_helper
# یا بدون نصب: مسیر packages/agent_helper را به sys.path اضافه کنید

افزودن به پروژه#

Python
# settings.py
INSTALLED_APPS = [
    # ...
    'rest_framework',
    'django_jalali',
    'agent_helper',
    'myplugin',            # افزونه‌ی شما
]
Python
# urls.py
from django.urls import include, path

urlpatterns = [
    # ...
    path('api/assistant/', include('agent_helper.urls')),
]
Shell
python manage.py migrate agent_helper

بررسی نصب#

Shell
python manage.py check            # خطای agent_helper.E001 یعنی ابزاری به اقدام ثبت‌نشده اشاره می‌کند
python manage.py test agent_helper

جدول‌هایی که ساخته می‌شوند: گفتگو، پیام، اقدام معلق، ممیزی، لاگ درخواست، لاگ مدل و لاگ ابزار (فهرست کامل در مفاهیم).
