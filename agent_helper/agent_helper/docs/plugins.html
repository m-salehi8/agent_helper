نوشتن افزونه

ساختار، ثبت و قواعد یک افزونه

افزونه یک اپ معمولی Django است که در AppConfig.ready() یک شیء Plugin را ثبت می‌کند. هسته هیچ‌چیزی درباره‌ی دامنه نمی‌داند؛ همه‌ی دانش (ابزار، اقدام، قواعد پرامپت، مسیر سریع) در افزونه است.

ساختار پیشنهادی#

myplugin/
├── apps.py          # register(PLUGIN) در ready()
├── models.py        # مدل‌های دامنه (اگر لازم است)
├── plugin.py        # ToolSpec ها، ActionKind ها، PromptFragment ها، FastRoute ها و PLUGIN
├── services.py      # منطق دامنه (کوئری‌ها، اعتبارسنجی، اجرا)
└── tests/

Plugin#

Plugin(name, tools=(), actions=(), catalogs=(), prompt_fragments=(), fast_routes=(), attachment_tags=())
فیلدنوعتوضیح
namestrنام یکتا؛ ثبت دوباره با همین نام جایگزین قبلی می‌شود
toolsToolSpec[]ابزارها؛ نام ابزار باید در همه‌ی افزونه‌ها یکتا باشد
actionsActionKind[]نوع‌های اقدام معلق؛ kind یکتا
catalogsCatalogProvider[]کاتالوگ موجودیت‌ها برای سؤال «کدام؟»
prompt_fragmentsPromptFragment[]قواعد پرامپت
fast_routesFastRoute[]مسیرهای بدون LLM
attachment_tagstuple[str]برچسب‌هایی که وقتی پیام تصویر دارد انتخاب می‌شوند

ثبت#

Python
from django.apps import AppConfig

class MyPluginConfig(AppConfig):
    name = 'myplugin'

    def ready(self):
        import agent_helper
        from myplugin.plugin import PLUGIN
        agent_helper.register(PLUGIN)

ترتیب افزونه‌ها همان ترتیب INSTALLED_APPS است و ترتیب ابزارها، مسیرها و قواعد هم‌ترتیب را تعیین می‌کند. manage.py check ناسازگاری‌ها را گزارش می‌کند (agent_helper.E001: ابزار پیشنهاددهنده‌ای که نوع اقدامش ثبت نشده).

قواعد طلایی#

  1. ابزار هرگز شناسه‌ی کاربر را از آرگومان نخواند؛ هر کوئری با user ورودی فیلتر شود.
  2. ابزار هرگز چیزی را تغییر ندهد؛ تغییر فقط در ActionKind.execute. ابزار فقط ctx.propose() می‌کند.
  3. execute همه‌چیز را دوباره بررسی کند (ممکن است داده بعد از پیشنهاد عوض شده باشد) و برای هر مورد ممیزی بنویسد.
  4. خروجی ابزار کوتاه و ساختاریافته باشد؛ مدل از روی آن پاسخ می‌سازد و رابط کاربری از رویدادهایش کارت.
  5. متن‌های داخل داده (عنوان، یادداشت) را «داده» بدانید نه دستور؛ قاعده‌ی تزریق هسته همیشه در پرامپت هست.

نمونه‌ی کامل#

پکیج agent-helper-demo (فایل agent_helper_demo/plugin.py) یک افزونه‌ی کامل و کوچک است: دو ابزار فقط‌خواندنی، یک ابزار پیشنهاد با اقدام add_note، یک مسیر سریع («چند روز مرخصی دارم؟») و یک قاعده‌ی پرامپت، همراه با تست‌ها.

چند افزونه کنار هم#

چند افزونه می‌توانند هم‌زمان نصب باشند؛ مدل ابزارهای همه را می‌بیند (یا با انتخاب ابزار فقط مرتبط‌ها را). از برچسب‌های مجزا (tags) استفاده کنید تا انتخاب ابزار درست کار کند.
