لاگ‌ها#

مدلیک ردیف برایفیلدهای مهم
AssistantRequestLogهر پیام کاربرpath (fast/llm/error)، fast_reason، intent، intent_confidence، تعداد فراخوانی‌ها، توکن، duration_ms، error
ModelCallLogهر فراخوانی مدلkind (intent/chat/vision)، model، ok، attempts، توکن، مدت، detail (پاسخ‌های مدل سبک یا ابزارهای درخواستی و offered)
ToolCallLogهر اجرای ابزارname، arguments، ok، result_summary، مدت
ActionAuditLogهر اجرای واقعیکاربر، اقدام، شناسه‌ی مورد، مبلغ، وضعیت، توضیح

ثبت لاگ هرگز پاسخ را خراب نمی‌کند؛ خطای ذخیره‌ی لاگ فقط در logger هشدار می‌شود.

دلیل‌های ارجاع به LLM (fast_reason)#

مقدارمعنی
disabledمسیر سریع خاموش است
<mode>_dialogگفتگو در حالت چندمرحله‌ای
<route>_requestدروازه‌ی بدون handler (همیشه LLM)
classifier_errorمدل سبک در دسترس نبود یا timeout
a_or_b_ambiguousدو دروازه هم‌زمان مطمئن
no_routeهیچ مسیری پاسخ نداد
سایردلیلی که Defer افزونه داده (مثلاً low_intent_confidence)

ادمین#

همه‌ی مدل‌ها در ادمین ثبت می‌شوند (فقط‌خواندنی). فهرست لاگ درخواست‌ها بالای جدول خلاصه‌ی فیلتر فعلی را نشان می‌دهد: سهم مسیر سریع، میانگین مدت هر مسیر و جمع توکن.

Python
AGENT_HELPER = {'ADMIN_BASE': 'myproject.admin.BaseModelAdmin', 'ADMIN_INLINE_BASE': 'myproject.admin.BaseTabularInline'}

معیارهای پیشنهادی پایش#

Python
from django.db.models import Avg, Count, Q, Sum
from agent_helper.models import AssistantRequestLog

AssistantRequestLog.objects.filter(created_at__gte=since).aggregate(
    total=Count('id'), fast=Count('id', filter=Q(path='fast')), errors=Count('id', filter=Q(status='error')),
    avg_llm_ms=Avg('duration_ms', filter=Q(path='llm')), tokens=Sum('input_tokens') + Sum('output_tokens'))

AssistantRequestLog.objects.values('fast_reason').annotate(n=Count('id')).order_by('-n')[:10]
  • نسبت مسیر سریع به LLM و دلیل‌های رایج ارجاع.
  • درصد خطای مدل (ModelCallLog.ok=False).
  • میانگین توکن مسیر LLM (اثر انتخاب ابزار).
  • اقدام‌های منقضی‌شده (پیشنهادهایی که کاربر تایید نکرد).
