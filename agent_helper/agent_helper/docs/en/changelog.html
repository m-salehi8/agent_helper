Changelog

Version history

0.1.0b1 — beta#

  • First beta pre-release; not yet a stable release. The API and settings may change before 1.0.
  • Documentation in English and Persian, shipped inside the wheel.
  • Version string follows PEP 440 (agent_helper.__version__); install with --pre or an exact pin.

0.1.0 (internal)#

  • First generic version.
  • Plugin contract: ToolSpec, ActionKind, CatalogProvider, PromptFragment, FastRoute, Plugin.
  • Generic pending actions: preview from ActionKind.preview, status stored by the core, execution errors audited.
  • Generic fast path with Jev questions from plugins; a local-model backend.
  • Selection of tools and rules relevant to the message (TOOL_SELECTION).
  • AGENT_HELPER settings with environment-variable support; no internet defaults.
  • Example plugin agent-helper-demo with a standalone project.
