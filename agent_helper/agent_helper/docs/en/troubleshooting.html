Troubleshooting and FAQ

Common errors and fixes

SymptomCause and fix
Every answer is "could not connect to the provider"LLM_BASE_URL is not set or the server is unreachable
"An error occurred while talking to the AI server"An HTTP error from the model server; see ModelCallLog.error (e.g. 410 deprecated model, 503 quota)
Empty LLM answer or broken JSONSome gateways stream without stream: false; the core sends it explicitly. The model must support tool calling
The fast path never runsUSE_FAST_ROUTER, JEV_BASE_URL/JEV_API_KEY; fast_reason in the log says why
agent_helper.E001 in checkA tool has proposes whose ActionKind is not registered
ValueError "action kind … is not registered"ctx.propose with a wrong kind, or the plugin defining the action is not installed
No action card appearsThe tool must use ctx.propose (not create a PendingAction directly)
Confirm returns 400 "expired"The deadline passed; expires_minutes or ACTION_EXPIRES_MINUTES
The stream arrives all at onceProxy buffering; proxy_buffering off
The model guesses valuesWeak model; make the domain prompt rule more explicit and keep validation in the tool (the confirm card is the last barrier)
The model lacks a needed toolTOOL_SELECTION='all' or fix tags/intent_tags; check ModelCallLog.detail.offered
429 from chatUser rate limit; PER_MINUTE_LIMIT and DAILY_LIMIT

FAQ#

Does it work without the fast path?#

Yes; every message goes to the LLM. The fast path is only an optimisation.

Can the model be changed per message?#

run_assistant_agent(..., provider=...) accepts any provider; the default view reads it from settings.

Is Persian required?#

The core rules and user-facing messages are in Persian; replace the identity and rule.* keys to change the prompt language. Dates are Jalali (django-jalali).

How much conversation history does the model get?#

All user and assistant messages of the same conversation; tool outputs of earlier turns are not stored, so the model calls the tool again when needed.

Is it production ready?#

Not yet: this is a beta (0.1.0b1). It is tested end to end, but the API may change before 1.0; pin the exact version.
