Fast path and Jev

Answers without the LLM for frequent messages; gates, main routes and catalogs

Frequent, simple messages ("hi", "my orders", "how many leave days do I have?") do not need the LLM. The fast path decides with regexes and one light-model call and runs the tool directly — only when all signals are confident.

Turning it on

AGENT_HELPER['USE_FAST_ROUTER'] = '1' (or ASSISTANT_USE_FAST_ROUTER=1). Off ⇒ every message goes to the LLM.

Decision order#

  1. The conversation is in a mode (conversation.mode) ⇒ LLM (reason: <mode>_dialog).
  2. Gate routes in order: if guard(text) is true ⇒ that route, without the light model.
  3. One light-model call with all questions (error or timeout ⇒ LLM with reason classifier_error).
  4. Yes/no gate questions: two confident gates ⇒ LLM (a_or_b_ambiguous); one ⇒ that route (unless gate_veto).
  5. Main routes in order with the light-model answers; none ⇒ LLM (no_route).

FastRoute#

RouteRequest#

MemberDescription
user, conversation, textInputs
clsLight-model answers: {key: {"choice", "confidence", "p"?}}; None when it came from a guard

gate_pProbability of "yes" per gate: {route_name: p}

Return Defer('reason') to hand over to the LLM; the reason is kept in the log (fast_reason).

Example: a gate route with a regex#

Python
import re
from agent_helper.plugins import FastRoute

LEAVE = re.compile(r'\bleave\b', re.I)
ASK = re.compile(r'how many|how much|left|remaining', re.I)

def leave_route(req):
    result = req.run_tool('get_leave_balance', {})
    return req.reply(f'You have {result["remaining_days"]} leave days left.')

ROUTE = FastRoute(name='leave', handler=leave_route, tags=('leave',),
                  guard=lambda t: bool(LEAVE.search(t) and ASK.search(t)))

Example: a main route with an intent question#

Python
from agent_helper.plugins import Defer, FastRoute

QUESTIONS = {
    'intent': {
        'type': 'choice',
        'instructions': 'The user writes to a shop assistant. What does the user want?',
        'criteria': {
            'list': 'List or filter their orders',
            'smalltalk': 'Greeting, thanks or help',
            'other': 'Anything else',
        },
    },
}

def orders_route(req):
    intent = req.cls['intent']
    if intent['confidence'] < req.threshold:
        return Defer('low_intent_confidence')
    if intent['choice'] == 'smalltalk':
        return req.reply('Hi! I can show you your orders.')
    if intent['choice'] == 'list':
        result = req.run_tool('list_orders', {})
        return req.reply(f'You have {result["count"]} orders.',
                         [{'event': 'order_list', 'items': result['orders']}])
    return Defer(f'intent_{intent["choice"]}')

ROUTE = FastRoute(name='orders', handler=orders_route, questions=QUESTIONS,
                  intent_tags={'list': ('orders',)})

Example: a gate that always sends to the LLM#

Python
CREATE = FastRoute(
    name='create',                                # log reason: create_request
    guard=lambda t: 'submit' in t.lower(),
    gate_question={'type': 'noul', 'instructions': 'The user wants to submit a NEW request.',
                   'criteria': {'true': 'Asks to create or register something new', 'false': 'Anything else'}},
    tags=('create',),
    order=10,
)

CatalogProvider#

If users refer to entities by name ("my last order", "the Samsung phone"), build a catalog so the core can give the light model a "which one?" question, with text matching as a fallback.

Python
from agent_helper import nlu
from agent_helper.plugins import CatalogEntry, CatalogProvider


class ProductCatalog(CatalogProvider):
    name = 'products'
    question_key = 'product'                         # answer key in req.cls
    instructions = 'Which product does the message refer to?'
    none_label = 'No specific product is mentioned'

    def entries(self):
        return [CatalogEntry(key=str(p.id), title=p.title, aliases=tuple(p.aliases), description=p.summary, data=p)
                for p in Product.objects.filter(active=True)]


def my_route(req):
    entry = nlu.resolve_catalog(ProductCatalog(), req.cls, req.text)   # confident light-model answer, else text match

Amounts and numbers in code

The light model is not a calculator. Extract amounts, dates and ids with code (agent_helper.fa.extract_amount for Persian amounts). Send any constraint the fast path does not understand ("all except the first", a person's name) to the LLM so it is not silently ignored.
