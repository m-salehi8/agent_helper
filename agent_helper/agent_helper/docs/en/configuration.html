Configuration

AGENT_HELPER settings, environment variables and common examples

All settings live in one AGENT_HELPER dict in settings.py. Each key is resolved in this order:

  1. settings.AGENT_HELPER[key]
  2. the matching environment variable (if any)
  3. the default value

Values are read at the moment of use, so changing an environment variable in tests (mock.patch.dict(os.environ)) takes effect immediately.

Minimal setup#

Python
AGENT_HELPER = {
    'LLM_PROVIDER': 'openai',
    'LLM_BASE_URL': 'http://llm.internal:8000/v1',
    'LLM_MODEL': 'qwen3',
}

Fast path with Jev#

Python
AGENT_HELPER = {
    # ...
    'USE_FAST_ROUTER': '1',
    'INTENT_BACKEND': 'jev',
    'JEV_BASE_URL': 'http://jev.internal',     # same /v1/systemone contract
    'JEV_API_KEY': '...',
    'FAST_THRESHOLD': 0.8,
}

Fast path with a local model#

Python
AGENT_HELPER = {
    # ...
    'USE_FAST_ROUTER': '1',
    'INTENT_BACKEND': 'llm',                    # any OpenAI-compatible server that returns logprobs
    'INTENT_BASE_URL': 'http://vllm.internal:8000/v1',
    'INTENT_MODEL': 'qwen3-1.7b',
}

With environment variables#

Shell
ASSISTANT_LLM_PROVIDER=openai
ASSISTANT_LLM_BASE_URL=http://llm.internal:8000/v1
ASSISTANT_LLM_API_KEY=...
ASSISTANT_LLM_MODEL=qwen3
ASSISTANT_USE_FAST_ROUTER=1
TYPESAFE_BASE_URL=http://jev.internal
TYPESAFE_API_KEY=...

Admin with your project's theme#

Python
AGENT_HELPER = {
    # ...
    'ADMIN_BASE': 'myproject.admin.BaseModelAdmin',       # your project's base admin class
    'ADMIN_INLINE_BASE': 'myproject.admin.BaseTabularInline',
    # 'REGISTER_ADMIN': False,                             # register no admin at all
}

Assistant identity in the prompt#

Python
AGENT_HELPER = {
    # ...
    'ASSISTANT_TITLE': 'Shop assistant',
    'ASSISTANT_MISSION': "Your job is to answer briefly and precisely about the user's orders.",
}

The full list of keys is in the settings reference.

No internet defaults

If LLM_BASE_URL is not set, no LLM request is made and the user gets a "could not connect to the provider" message. Jev without JEV_BASE_URL fails and the message falls through to the LLM.
