Logs, admin and monitoring

What is recorded and how to look at it

Logs#

ModelOne row perKey fields
AssistantRequestLogUser messagepath (fast/llm/error), fast_reason, intent, intent_confidence, call counts, tokens, duration_ms, error
ModelCallLogModel callkind (intent/chat/vision), model, ok, attempts, tokens, duration, detail (light-model answers or requested tools and offered)
ToolCallLogTool runname, arguments, ok, result_summary, duration
ActionAuditLogReal executionUser, action, item id, amount, status, detail

Logging never breaks a response; a failure to store a log is only a warning in the logger.

Reasons for falling back to the LLM (fast_reason)#

ValueMeaning
disabledThe fast path is off
<mode>_dialogThe conversation is in a multi-step mode
<route>_requestA gate without a handler (always LLM)
classifier_errorThe light model was unavailable or timed out
a_or_b_ambiguousTwo gates were confident at once
no_routeNo route answered
OtherThe reason a plugin gave with Defer (e.g. low_intent_confidence)

Admin#

All models are registered in the admin (read-only). Above the request log table a summary of the current filter is shown: fast-path share, average duration per path and total tokens.

Python
AGENT_HELPER = {'ADMIN_BASE': 'myproject.admin.BaseModelAdmin', 'ADMIN_INLINE_BASE': 'myproject.admin.BaseTabularInline'}

Suggested monitoring metrics#

Python
from django.db.models import Avg, Count, Q, Sum
from agent_helper.models import AssistantRequestLog

AssistantRequestLog.objects.filter(created_at__gte=since).aggregate(
    total=Count('id'), fast=Count('id', filter=Q(path='fast')), errors=Count('id', filter=Q(status='error')),
    avg_llm_ms=Avg('duration_ms', filter=Q(path='llm')), tokens=Sum('input_tokens') + Sum('output_tokens'))

AssistantRequestLog.objects.values('fast_reason').annotate(n=Count('id')).order_by('-n')[:10]
  • Fast-path to LLM ratio and the common fallback reasons.
  • Model error rate (ModelCallLog.ok=False).
  • Average tokens on the LLM path (effect of tool selection).
  • Expired actions (proposals the user did not confirm).
