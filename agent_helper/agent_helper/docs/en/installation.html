Getting started
Beta release (0.1.0b1). This package is not a stable release yet; the API and settings may change before 1.0.

Installation

Offline install from wheels, adding the app to a project, and migrate

Install from wheels (offline)#

Production servers often have no internet access; prepare the wheels and dependencies on a development machine and carry them over.

  1. Build the package wheels (no internet needed):
    Shell
    cd packages
pip wheel --no-deps --no-build-isolation --no-index -w dist ./agent_helper ./agent_helper_demo
  2. Collect dependencies (once, on a machine with access):
    Shell
    pip download --only-binary=:all: -d wheelhouse \
    Django==5.0.4 djangorestframework==3.15.1 django-jalali==6.2.1 jdatetime==5.0.0 requests==2.32.3
  3. Install on the server:
    Shell
    pip install --no-index --find-links wheelhouse --find-links dist --pre agent-helper
Beta version

The current release is a pre-release (0.1.0b1), so pip only picks it with --pre or an exact pin such as agent-helper==0.1.0b1.

Versions

The versions above are the tested ones. The Python version of the download machine and the server must match (binary wheels such as charset-normalizer).

Install from source (development)#

Shell
pip install -e packages/agent_helper
# or without installing: add packages/agent_helper to sys.path

Add to your project#

Python
# settings.py
INSTALLED_APPS = [
    # ...
    'rest_framework',
    'django_jalali',
    'agent_helper',
    'myplugin',            # your plugin
]
Python
# urls.py
from django.urls import include, path

urlpatterns = [
    # ...
    path('api/assistant/', include('agent_helper.urls')),
]
Shell
python manage.py migrate agent_helper

Verify the installation#

Shell
python manage.py check            # agent_helper.E001 means a tool points to an unregistered action kind
python manage.py test agent_helper
