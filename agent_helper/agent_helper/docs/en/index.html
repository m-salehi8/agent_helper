agent-helper

A pluggable assistant for Django: an LLM with tools, a no-LLM fast path, and actions that only the user executes

agent-helper is a Django app for building a conversational assistant on top of your own system's data. The core knows nothing about any domain; every use case (orders, notes, office requests, …) is a plugin that registers its own tools, actions and rules.

🚀 Quick startFrom an empty Django project to the first chat in 10 minutes 🧩 Writing a pluginTools, pending actions, fast routes and prompt rules 📡 API and SSEEndpoints, events, request and response samples 🛡️ Security modelWhy the model never executes anything on its own

What you get#

  • Agent loop with tools on any OpenAI-compatible server (vLLM, llama.cpp, …) or Anthropic; at most 6 rounds.
  • Fast path without the LLM: regex plus one call to a light model (Jev, or a local model with logprobs) for frequent messages; any doubt ⇒ LLM.
  • Pending actions: the model only creates a proposal; execution happens only when the user presses the button, with a lock, an expiry, idempotency and an audit trail.
  • SSE streaming for text, tool status, cards and errors.
  • Image attachments (e.g. an invoice) read by a vision model, with arithmetic checks.
  • Full logging: every message, model call and tool call with timing and tokens; admin included.
  • Token reduction: only the tools and rules relevant to the message are sent to the model.
  • Rate limits per minute and per day for each user.
  • Offline: no default address points to the internet; everything is configured by URL.

At a glance#

Python
# myplugin/plugin.py
from agent_helper.plugins import Plugin, ToolSpec

def list_orders(user, args, ctx):
    return {'orders': [{'id': o.id, 'total': o.total} for o in user.orders.all()[:20]]}

PLUGIN = Plugin(name='orders', tools=[
    ToolSpec('list_orders', "List the user's orders", {'type': 'object', 'properties': {}}, list_orders),
])

The user writes "show my orders", the model calls the list_orders tool (always for request.user) and the answer is streamed to the UI as SSE.

Requirements#

  • Python ≥ 3.10, Django ≥ 4.2, Django REST framework ≥ 3.14
  • django-jalali and jdatetime (Jalali dates), requests
  • An LLM server with tool calling support (for the LLM path)
  • Optional: Jev or a local model with logprobs for the fast path; a vision model for image attachments
