HTTP API and SSE events

Endpoints, bodies, status codes and every stream event

All endpoints are IsAuthenticated and work with your project's DRF authentication classes (JWT, session, token). Paths are relative to where you included agent_helper.urls (/api/assistant/ in the examples).

MethodPathURL namePurpose
POSTchat/assistant_chatSend a message; SSE streamed response
GETconversations/assistant_conversationsThe user's conversations
GETconversations/<id>/assistant_conversation_detailOne conversation with its messages
POSTactions/<id>/confirm/assistant_action_confirmExecute a pending action
POSTactions/<id>/cancel/assistant_action_cancelCancel a pending action

POST chat/#

FieldTypeDescription
messagestring, required, max 5000The user text
conversation_idint, optionalContinue a previous conversation (the user's own only; otherwise 404); empty = new conversation
imagedata URL, optionalpng/jpg/webp image (image attachments)
HTTP
POST /api/assistant/chat/
Authorization: Bearer eyJ...
Content-Type: application/json

{"message": "Show my open orders", "conversation_id": 12}

The response is 200 text/event-stream; each event is a data: <JSON> line followed by a blank line. The Cache-Control: no-cache and X-Accel-Buffering: no headers are set so nginx passes it through unbuffered.

StatusWhen
200Stream (even LLM errors arrive as an error event)
400Invalid body (DRF error JSON)
401Not authenticated
404conversation_id does not belong to the user
429Per-minute/daily limit or invalid image; one error event with a user-facing message

SSE events#

eventFieldsUse in the UI
tool_statusstatusStatus bar ("Working on …")
tokentextAnswer text (final text only; text before a tool call is not shown)
pending_actionaction_id, expires_at + the preview fieldsConfirm/cancel card
attachment_datadata, warning"Read from the image" card
doneconversation_id, message_id, path (fast or llm)End; keep the conversation id
errormessage (+ detail in DEBUG)Warning
Plugin eventsFree-form (from ToolSpec.events)Tables, status cards, …
data: {"event": "tool_status", "status": "Searching orders..."}

data: {"event": "order_list", "items": [{"id": 5, "total": 120000}], "count": 1}

data: {"event": "token", "text": "You have one open order."}

data: {"event": "done", "conversation_id": 12, "message_id": 88, "path": "fast"}

POST actions/<id>/confirm/#

Any JSON body, passed unchanged to ActionKind.execute as params.

HTTP
POST /api/assistant/actions/45/confirm/
{"node_ids": [1024, 1031], "unchecked": "keep"}

200 {"message": "2 items approved.", "action_id": 45, "status": "confirmed",
     "results": [{"node_id": 1024, "status": "success", "detail": "..."}]}
StatusBody
200Execution result; a repeated confirm: {"already_confirmed": true, "status", "results"}
400{"error"}: expired, status not pending, unknown kind or invalid parameter
403The action belongs to another user
404No such action
500The executor raised; the action is failed and audited
