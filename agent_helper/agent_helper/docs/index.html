agent-helper

دستیار هوشمند افزونه‌پذیر برای Django: LLM با ابزار، مسیر سریع بدون LLM و اقدام‌هایی که فقط کاربر اجرا می‌کند

agent-helper یک اپ Django برای ساختن دستیار گفتگومحور روی داده‌های سامانه‌ی خودتان است. هسته‌ی آن هیچ دامنه‌ای را نمی‌شناسد؛ هر کاربرد (سفارش، یادداشت، درخواست‌های اداری، …) یک افزونه است که ابزارها، اقدام‌ها و قواعد خودش را ثبت می‌کند.

🚀 شروع سریعاز یک پروژه‌ی خالی Django تا اولین گفتگو در ۱۰ دقیقه 🧩 نوشتن افزونهابزار، اقدام معلق، مسیر سریع و قاعده‌ی پرامپت 📡 API و SSEendpointها، رویدادها و نمونه‌ی درخواست و پاسخ 🛡️ مدل امنیتیچرا مدل هیچ‌وقت خودش چیزی را اجرا نمی‌کند

چه چیزی آماده است#

  • حلقه‌ی عامل با ابزار روی هر سرور سازگار با OpenAI (vLLM، llama.cpp، …) یا Anthropic؛ حداکثر ۶ دور.
  • مسیر سریع بدون LLM: regex و یک فراخوانی مدل سبک (Jev یا مدل لوکال با logprobs) برای پیام‌های پرتکرار؛ هر تردید ⇐ LLM.
  • اقدام معلق: مدل فقط «پیشنهاد» می‌سازد؛ اجرا فقط با دکمه‌ی کاربر، با قفل، مهلت، idempotent و ممیزی.
  • استریم SSE برای متن، وضعیت ابزار، کارت‌ها و خطا.
  • پیوست تصویر (مثلاً فاکتور) با مدل بینایی و کنترل حسابی.
  • لاگ کامل: هر پیام، هر فراخوانی مدل و هر ابزار با زمان و توکن؛ ادمین آماده.
  • کاهش توکن: فقط ابزارها و قاعده‌های مرتبط با پیام به مدل داده می‌شود.
  • سقف نرخ دقیقه‌ای و روزانه برای هر کاربر.
  • آفلاین: هیچ نشانی پیش‌فرضی به اینترنت اشاره نمی‌کند؛ همه‌چیز با URL قابل تنظیم است.

یک نگاه سریع#

Python
# myplugin/plugin.py
from agent_helper.plugins import Plugin, ToolSpec

def list_orders(user, args, ctx):
    return {'orders': [{'id': o.id, 'total': o.total} for o in user.orders.all()[:20]]}

PLUGIN = Plugin(name='orders', tools=[
    ToolSpec('list_orders', 'فهرست سفارش‌های کاربر', {'type': 'object', 'properties': {}}, list_orders),
])

کاربر می‌نویسد «سفارش‌هایم را نشان بده»، مدل ابزار list_orders را صدا می‌زند (همیشه برای request.user) و پاسخ به‌صورت SSE به رابط کاربری می‌رسد.

نیازمندی‌ها#

  • Python ≥ 3.10، Django ≥ 4.2، Django REST framework ≥ 3.14
  • django-jalali و jdatetime (تاریخ‌های شمسی)، requests
  • یک سرور مدل زبانی با پشتیبانی tool calling (برای مسیر LLM)
  • اختیاری: Jev یا یک مدل لوکال با logprobs برای مسیر سریع؛ مدل بینایی برای پیوست تصویر
