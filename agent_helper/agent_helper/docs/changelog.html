تاریخچه‌ی نسخه‌ها

0.1.0b1 — بتا#

  • نخستین پیش‌انتشار بتا؛ هنوز نسخه‌ی پایدار نیست و تا 1.0 ممکن است API و تنظیمات تغییر کنند.
  • مستندات به دو زبان فارسی و انگلیسی، همراه wheel.
  • رشته‌ی نسخه طبق PEP 440 (agent_helper.__version__)؛ نصب با --pre یا نسخه‌ی دقیق.

0.1.0 (داخلی)#

  • نخستین نسخه‌ی جنریک.
  • قرارداد افزونه: ToolSpec، ActionKind، CatalogProvider، PromptFragment، FastRoute، Plugin.
  • اقدام معلق جنریک: پیش‌نمایش از ActionKind.preview، ذخیره‌ی وضعیت در هسته، ممیزی خطای اجرا.
  • مسیر سریع جنریک با سؤال‌های Jev از افزونه‌ها؛ backend مدل لوکال.
  • انتخاب ابزار و قاعده‌های مرتبط با پیام (TOOL_SELECTION).
  • تنظیمات AGENT_HELPER با پشتیبانی متغیرهای محیطی؛ بدون نشانی پیش‌فرض اینترنتی.
  • افزونه‌ی نمونه‌ی agent-helper-demo و پروژه‌ی مستقل.
