مسیر سریع و Jev

پاسخ بدون LLM برای پیام‌های پرتکرار؛ دروازه‌ها، مسیرهای اصلی و کاتالوگ

پیام‌های پرتکرار و ساده («سلام»، «سفارش‌هایم»، «چند روز مرخصی دارم؟») لازم نیست به LLM بروند. مسیر سریع با regex و یک فراخوانی مدل سبک تصمیم می‌گیرد و ابزار را مستقیم اجرا می‌کند. فقط وقتی همه‌ی سیگنال‌ها مطمئن‌اند.

روشن کردن

AGENT_HELPER['USE_FAST_ROUTER'] = '1' (یا ASSISTANT_USE_FAST_ROUTER=1). خاموش ⇐ همه‌ی پیام‌ها به LLM.

ترتیب تصمیم#

  1. گفتگو در حالتی است (conversation.mode) ⇐ LLM (دلیل: <mode>_dialog).
  2. مسیرهای دروازه به ترتیب order: اگر guard(text) درست بود ⇐ همان مسیر، بدون مدل سبک.
  3. یک فراخوانی مدل سبک با همه‌ی سؤال‌ها (خطا یا timeout ⇐ LLM با دلیل classifier_error).
  4. سؤال‌های بله/خیر دروازه‌ها: دو دروازه مطمئن ⇐ LLM (a_or_b_ambiguous)؛ یکی ⇐ همان مسیر (مگر gate_veto).
  5. مسیرهای اصلی به ترتیب با پاسخ‌های مدل سبک؛ هیچ‌کدام ⇐ LLM (no_route).

FastRoute#

FastRoute(name, handler=None, guard=None, gate_question=None, gate_veto=None, questions={}, tags=(), intent_tags={}, order=100)
آرگومانتوضیح
nameنام مسیر؛ سؤال بله/خیرش با کلید is_<name> پرسیده می‌شود
handlerhandler(req: RouteRequest) -> reply | Defer | None؛ دروازه‌ی بدون handler یعنی «همیشه LLM»
guardcallable(text) -> bool regex ارزان؛ اگر جور شد مسیر بدون مدل سبک اجرا می‌شود
gate_questionسؤال بله/خیر Jev ({"type": "noul", ...})
gate_vetocallable(text) -> bool؛ پاسخ «بله»ی Jev را برای این متن نادیده می‌گیرد
questionsسؤال‌های انتخابی مسیر اصلی (در هر دو backend پرسیده می‌شوند)
tagsبرچسب‌های ابزار/پرامپت مرتبط (برای انتخاب ابزار در مسیر LLM)
intent_tagsنگاشت پاسخ سؤال intent به برچسب‌ها
orderترتیب اجرا (کوچک‌تر اول)

RouteRequest#

عضوتوضیح
user، conversation، textورودی‌ها
clsپاسخ‌های مدل سبک: {key: {"choice", "confidence", "p"?}}؛ None اگر از guard آمده
thresholdآستانه‌ی اطمینان (FAST_THRESHOLD)
gate_pاحتمال «بله» هر دروازه: {route_name: p}
run_tool(name, args)اجرای ابزار ثبت‌شده برای همین کاربر، با لاگ
reply(text, events=None)پاسخ نهایی؛ کارت پیشنهادهای ساخته‌شده خودکار اضافه می‌شود

برای رفتن به LLM Defer('reason') برگردانید؛ دلیل در لاگ (fast_reason) می‌ماند.

نمونه: مسیر دروازه با regex#

Python
import re
from agent_helper.plugins import FastRoute

LEAVE = re.compile(r'مرخصی')
ASK = re.compile(r'چند|چقدر|مانده|باقی')

def leave_route(req):
    result = req.run_tool('get_leave_balance', {})
    return req.reply(f'{result["remaining_days"]} روز مرخصی برایتان مانده است.')

ROUTE = FastRoute(name='leave', handler=leave_route, tags=('leave',),
                  guard=lambda t: bool(LEAVE.search(t) and ASK.search(t)))

نمونه: مسیر اصلی با سؤال نیت#

Python
from agent_helper.plugins import Defer, FastRoute

QUESTIONS = {
    'intent': {
        'type': 'choice',
        'instructions': 'The user writes in Persian to a shop assistant. What does the user want?',
        'criteria': {
            'list': 'List or filter their orders',
            'smalltalk': 'Greeting, thanks or help',
            'other': 'Anything else',
        },
    },
}

def orders_route(req):
    intent = req.cls['intent']
    if intent['confidence'] < req.threshold:
        return Defer('low_intent_confidence')
    if intent['choice'] == 'smalltalk':
        return req.reply('سلام! می‌توانم سفارش‌هایتان را نشان بدهم.')
    if intent['choice'] == 'list':
        result = req.run_tool('list_orders', {})
        return req.reply(f'{result["count"]} سفارش دارید.',
                         [{'event': 'order_list', 'items': result['orders']}])
    return Defer(f'intent_{intent["choice"]}')

ROUTE = FastRoute(name='orders', handler=orders_route, questions=QUESTIONS,
                  intent_tags={'list': ('orders',)})

backend مدل سبک#

backendسؤال‌هاتنظیم
jev (پیش‌فرض)سؤال‌های اصلی + بله/خیر دروازه‌ها + کاتالوگ‌ها، در یک درخواست /v1/systemoneJEV_BASE_URL، JEV_API_KEY، JEV_MODEL
llmفقط سؤال‌های اصلی؛ هر سؤال یک انتخاب تک‌حرفی با confidence از logprobsINTENT_BASE_URL، INTENT_MODEL
مبلغ و عدد با کد

مدل سبک ماشین‌حساب نیست. مبلغ، تاریخ و شناسه را با کد استخراج کنید (agent_helper.fa.extract_amount برای مبلغ فارسی). قیدی را که مسیر سریع نمی‌فهمد («بجز اولی»، نام شخص) به LLM بفرستید تا بی‌صدا نادیده گرفته نشود.
