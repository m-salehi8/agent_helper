«خطایی در ارتباط با سرور هوش مصنوعی»خطای HTTP از سرور مدل؛ ModelCallLog.error را ببینید (مثلاً 410 مدل منسوخ، 503 سهمیه)
پاسخ LLM خالی یا JSON خراببرخی دروازه‌ها بدون stream: false استریم می‌کنند؛ هسته آن را صریح می‌فرستد. مدل باید tool calling داشته باشد
مسیر سریع هیچ‌وقت اجرا نمی‌شودUSE_FAST_ROUTER، JEV_BASE_URL/JEV_API_KEY؛ fast_reason در لاگ دلیل را می‌گوید
agent_helper.E001 در checkابزاری proposes دارد که ActionKind آن ثبت نشده

کارت اقدام نمی‌آیدابزار باید از ctx.propose استفاده کند (نه ساخت مستقیم PendingAction)
تایید ۴۰۰ «منقضی شده»مهلت گذشته؛ expires_minutes یا ACTION_EXPIRES_MINUTES
استریم یک‌جا می‌رسدبافر پروکسی؛ proxy_buffering off
مدل مقدار حدس می‌زندمدل ضعیف؛ قاعده‌ی پرامپت دامنه را صریح‌تر کنید و اعتبارسنجی را در ابزار نگه دارید (کارت تایید آخرین سد است)
مدل ابزار لازم را نداردTOOL_SELECTION='all' یا برچسب‌ها/intent_tags را اصلاح کنید؛ ModelCallLog.detail.offered

پرسش‌های پرتکرار#

آیا بدون مسیر سریع هم کار می‌کند؟#

بله؛ همه‌ی پیام‌ها به LLM می‌روند. مسیر سریع فقط بهینه‌سازی است.

آیا می‌شود مدل را برای هر پیام عوض کرد؟#

run_assistant_agent(..., provider=...) ارائه‌دهنده‌ی دلخواه می‌گیرد؛ view پیش‌فرض از تنظیمات می‌خواند.

فارسی اجباری است؟#

قواعد هسته فارسی‌اند؛ با جایگزینی کلیدهای identity و rule.* می‌توانید زبان را عوض کنید. تاریخ‌ها شمسی (django-jalali) هستند.

تاریخچه‌ی گفتگو چقدر به مدل داده می‌شود؟#

همه‌ی پیام‌های user و assistant همان گفتگو؛ خروجی ابزارهای نوبت‌های قبل ذخیره نمی‌شود، پس مدل در صورت نیاز دوباره ابزار را صدا می‌زند.

برای محیط عملیاتی آماده است؟#

هنوز نه؛ این نسخه بتا است (0.1.0b1). سناریوها کامل تست شده‌اند ولی تا 1.0 ممکن است API تغییر کند؛ نسخه را دقیق pin کنید.
