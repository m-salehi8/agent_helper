پیکربندی

تنظیمات AGENT_HELPER، متغیرهای محیطی و نمونه‌های رایج

همه‌ی تنظیمات در یک دیکشنری AGENT_HELPER در settings.py هستند. هر کلید به این ترتیب خوانده می‌شود:

  1. settings.AGENT_HELPER[key]
  2. متغیر محیطی متناظر (اگر دارد)
  3. مقدار پیش‌فرض

مقدارها در لحظه‌ی استفاده خوانده می‌شوند؛ پس تغییر متغیر محیطی در تست‌ها (mock.patch.dict(os.environ)) بلافاصله اثر دارد.

حداقل تنظیم#

Python
AGENT_HELPER = {
    'LLM_PROVIDER': 'openai',
    'LLM_BASE_URL': 'http://llm.internal:8000/v1',
    'LLM_MODEL': 'qwen3',
}

مسیر سریع با Jev#

Python
AGENT_HELPER = {
    # ...
    'USE_FAST_ROUTER': '1',
    'INTENT_BACKEND': 'jev',
    'JEV_BASE_URL': 'http://jev.internal',     # همان قرارداد /v1/systemone
    'JEV_API_KEY': '...',
    'FAST_THRESHOLD': 0.8,
}

مسیر سریع با مدل لوکال#

Python
AGENT_HELPER = {
    # ...
    'USE_FAST_ROUTER': '1',
    'INTENT_BACKEND': 'llm',                    # هر سرور OpenAI-compatible که logprobs بدهد
    'INTENT_BASE_URL': 'http://vllm.internal:8000/v1',
    'INTENT_MODEL': 'qwen3-1.7b',
}

با متغیرهای محیطی#

Shell
ASSISTANT_LLM_PROVIDER=openai
ASSISTANT_LLM_BASE_URL=http://llm.internal:8000/v1
ASSISTANT_LLM_API_KEY=...
ASSISTANT_LLM_MODEL=qwen3
ASSISTANT_USE_FAST_ROUTER=1
TYPESAFE_BASE_URL=http://jev.internal
TYPESAFE_API_KEY=...

ادمین با قالب پروژه#

Python
AGENT_HELPER = {
    # ...
    'ADMIN_BASE': 'myproject.admin.BaseModelAdmin',       # کلاس پایه‌ی ادمین پروژه
    'ADMIN_INLINE_BASE': 'myproject.admin.BaseTabularInline',
    # 'REGISTER_ADMIN': False,                             # هیچ ادمینی ثبت نشود
}

هویت دستیار در پرامپت#

Python
AGENT_HELPER = {
    # ...
    'ASSISTANT_TITLE': 'دستیار فروشگاه',
    'ASSISTANT_MISSION': 'وظیفه‌ی شما پاسخ کوتاه و دقیق درباره‌ی سفارش‌های کاربر است.',
}

فهرست کامل کلیدها در مرجع تنظیمات.

بدون پیش‌فرض اینترنتی

اگر LLM_BASE_URL تنظیم نشده باشد، درخواست به LLM انجام نمی‌شود و کاربر پیام «امکان برقراری ارتباط… میسر نشد» می‌گیرد. Jev بدون JEV_BASE_URL خطا می‌دهد و پیام به LLM می‌رود.
