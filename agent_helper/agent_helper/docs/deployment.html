استقرار

نصب روی سرور آفلاین، nginx، مدل خودمیزبان و نصب روی جدول‌های قدیمی

چک‌لیست#

  • wheelها و wheelhouse روی سرور؛ pip install --no-index.
  • migrate.
  • نشانی‌های LLM، مدل سبک و بینایی در تنظیمات یا متغیر محیطی.
  • cache مشترک (Redis) برای سقف نرخ در چند پروسه.
  • nginx: بدون بافر برای مسیر chat/؛ timeout خواندن ≥ ۱۲۰ ثانیه.
  • سرور ASGI/WSGI با worker کافی: هر گفتگوی LLM یک worker را تا پایان استریم نگه می‌دارد.
location /api/assistant/chat/ {
    proxy_pass http://app;
    proxy_buffering off;
    proxy_read_timeout 180s;
}

مدل خودمیزبان#

  • LLM: vLLM یا هر سرور OpenAI-compatible با tool calling؛ LLM_PROVIDER='openai'. prefix caching توکن‌های تکراری پرامپت را ارزان می‌کند.
  • مدل سبک: Jev یا هر سرور با همان قرارداد /v1/systemone) یا یک مدل کوچک با logprobs (INTENT_BACKEND='llm').
  • بینایی: مدل VL روی همان سرور یا سرور جدا (VISION_*).

بعد از تغییر مدل، ارزیابی مسیریابی و یک سناریوی کامل هر افزونه را دوباره اجرا کنید.

نصب روی جدول‌های قدیمی (برچسب دیگر)#

اگر جدول‌ها از نسخه‌ای قبلی با برچسب اپ دیگری (مثلاً assistant) وجود دارند، بدون تغییر دیتابیس:

Python
# myproject/agent_apps.py
from agent_helper.apps import AgentHelperConfig

class AssistantConfig(AgentHelperConfig):
    name = 'agent_helper'
    label = 'my_old_label'      # همان جدول‌ها، content typeها، مجوزها و نام URLهای ادمین

# settings.py
INSTALLED_APPS += ['myproject.agent_apps.AssistantConfig']
MIGRATION_MODULES = {'my_old_label': 'myproject.old_migrations'}   # تاریخچه‌ی migration موجود
migration دستی

در این حالت makemigrations باید فقط روی برچسب قدیمی اجرا شود. migration اولیه‌ی خود پکیج (agent_helper/migrations) برای نصب تازه است.
